Найденные ошибки при тестировании 7 блюд (Щи, Котлеты, Мимоза, Медовик, Морс, Голубцы, Цезарь):
- В ходе комплексного ручного и автоматизированного тестирования активных дефектов и критических ошибок в программных модулях не обнаружено. Приложение работает абсолютно стабильно во всех штатных режимах.

Как предотвращены потенциальные ошибки (встроенная защита кода):
1. Появление системного текста "None" исключено на этапе разработки: в коде отрисовки карточек Tkinter заранее применены тернарные операторы проверки данных из SQLite. Если поле пустое, автоматически выводится безопасная текстовая заглушка.
2. Сбои при отображении картинок предотвращены за счет создания жестких ссылок на объекты PhotoImage (img_label.image = photo), что полностью защищает медиа-компоненты от преждевременного удаления сборщиком мусора Python.

Проверка граничных случаев (с учетом порога <= 12):
✅ Количество = 0 штук -> Ошибок нет. Статус: мало, цвет фона карточки: #ff8080
✅ Количество = 12 штук -> Ошибок нет. Точная физическая граница КИМ. Статус: мало, цвет фона: #ff8080
✅ Количество = 13 штук -> Ошибок нет. Граница нормы (+1). Статус: много, цвет фона: white
✅ Отсутствие изображения товара -> Ошибок нет. Выводится безопасная текстовая заглушка [НЕТ ФОТО]
✅ Длина наименования блюда > 100 символов -> Ошибок нет. Включен автоматический перенос строк, сетка GUI не ломается.
✅ Цена позиции > 1 000 000 руб. -> Ошибок нет. Число полностью умещается в границах лейбла.
✅ Смешанная кодировка (Кириллица + Латиница) -> Ошибок нет. Шрифт Calibri корректно отображает все символы.
